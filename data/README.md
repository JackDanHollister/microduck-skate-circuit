# re:Invent 2018

I used the re:Invent 2018 route published in [DeepRacer on AWS](https://github.com/aws-solutions/deepracer-on-aws/blob/e601a6a488a7c3444cf7a7f09e085724f2889d99/source/libs/reward-function-validation/routes/reinvent_base.npy). The file in this folder converts its six columns into centre, left and right XY arrays in metres. I removed the repeated finish point and rounded the coordinates to seven decimal places. Join the final point to the first to close the circuit. The measured centreline is 17.709 m and the lane is about 0.76 m wide.
